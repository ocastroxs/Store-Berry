# 🍓 StoreBerry

**StoreBerry** é um sistema de vendas simples e intuitivo, desenvolvido para gerenciar produtos e facilitar o processo de compra e venda em tempo real.  
O projeto combina um design moderno com uma estrutura leve e eficiente, ideal para pequenas lojas ou demonstrações de sistemas de e-commerce.

---

## 🚀 Visão Geral

O **StoreBerry** tem como objetivo oferecer uma plataforma funcional e atrativa para simular um sistema de vendas.  
Com uma interface amigável, o sistema permite visualizar produtos, adicionar ao carrinho e gerenciar itens com fluidez e responsividade.

> 🍇 *Slogan:* “Sabor e tecnologia no ponto certo!”

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura das páginas  
- **CSS3** — Estilização e layout responsivo  
- **JavaScript (ES6+)** — Lógica e interatividade no front-end  
- **Node.js** — Servidor local e manipulação de rotas  
- **Express.js** — Framework leve para gerenciamento do back-end
